# 用語集

B2クラウドのデータレイアウトに登場する主な用語の簡易説明です。正確な定義は公式情報をご確認ください。

| 用語 | 説明 |
|------|------|
| B2クラウド | ヤマト運輸の送り状（伝票）発行システム。CSV/Excel での外部データ取込みに対応。 |
| 送り状種類 | 発払い・コレクト・ネコポス等、伝票の種別。値により必須項目や利用可否が変わる（[早見表](送り状種類別必須項目.md)）。 |
| 発払い | 送料を発送人（ご依頼主）が負担する通常の宅急便。 |
| 着払い | 送料をお届け先（受取人）が支払う方式。 |
| コレクト（代金引換） | 商品代金を配達時に受取人から回収する方式。代金引換額・消費税額の入力が必要。 |
| EAZY | EC 向けの置き配対応配送サービス。受取人がメールのURLから受取方法を指定できる（[EAZY資料](EAZY送り状発行データレイアウト入出力用.md)）。 |
| ネコポス | ポスト投函型の小型配送サービス。投函予定/完了メールの項目を利用可能。 |
| クロネコゆうメール | 旧「メール便」。書籍・カタログ等の信書以外の荷物向け。 |
| クロネコゆうパケット | ポスト投函型の小型配送サービス。 |
| 宅急便コンパクト | 専用BOXを使う小型宅急便。コレクト併用版もある。 |
| タイム（タイムサービス） | 午前10時まで・午後5時まで等、時間を保証する配送。 |
| クール区分 | 冷凍・冷蔵などの温度帯指定。0/空白=通常, 1=クール冷凍, 2=クール冷蔵。 |
| 配達時間帯 | お届け希望の時間帯。0812(午前中), 1416, 1618, 1820, 1921 等のコードで指定。 |
| 営業所止置き | 受取人宅ではなく、指定のヤマト営業所で荷物を受け取る方式。営業所コードが必要。 |
| 個数口枠の印字 | 複数口（同一宛先の複数個口）発送時の口数枠の印字方法。 |
| 複数口くくりキー | 同一宛先の複数口をまとめるためのキー。発払（複数口）等で使用。 |
| クロネコwebコレクト | クレジットカード等のオンライン決済を伴うコレクト。加盟店番号・申込受付番号が必要。 |
| クロネコ収納代行 | 請求書同梱等で代金を回収する収納代行サービス。請求先・問合せ先の情報が必要。 |
| 直送り | 連携管理番号・通知メールアドレスを用いる連携機能（出荷データ連携）。 |
| お客様管理番号 | 発送側が任意に付与できる管理用の番号（最大50文字）。 |
| ご請求先顧客コード / 分類コード | 運賃の請求先を識別するコード。 |
| 運賃管理番号 | 運賃の管理単位を示す番号。 |
| お届け予定/完了eメール | 配達前・配達後に受取人へ送る通知メール。利用区分・アドレス・メッセージで構成。 |
| 入力機種 | データ作成端末の区分。1=PC, 2=携帯電話。EAZY 利用時は「1」固定。 |
