# 送り状種類別 必須項目・制約 早見表

[送り状発行データレイアウト](B2送り状発行データレイアウト入出力用.md) の備考をもとに、送り状種類ごとの必須項目・固有制約を整理した早見表です。実際の判定は公式仕様が優先されます。

## 送り状種類の値

| 値 | 種類 |
|----|------|
| 0 | 発払い |
| 1 | EAZY（置き配）※公式FAQに基づく値 |
| 2 | コレクト |
| 3 | クロネコゆうメール |
| 4 | タイム |
| 5 | 着払い |
| 6 | 発払い（複数口） |
| 7 | クロネコゆうパケット |
| 8 | 宅急便コンパクト |
| 9 | 宅急便コンパクトコレクト |
| A | ネコポス |

## 全種類で共通して必須となる主な項目

- 送り状種類（2）、出荷予定日（5）
- お届け先郵便番号（11）、お届け先住所（12）、お届け先名（16）
- お届け先電話番号（9）※宅急便系（クロネコゆうメールでは必須対象外）

## 種類ごとの固有の必須項目・制約

| 種類 | 固有の必須項目 / 主な制約 |
|------|--------------------------|
| 発払い | 特になし（共通必須のみ）。ご請求先顧客コード・運賃管理番号は宅急便で必須。 |
| コレクト / 宅急便コンパクトコレクト | コレクト代金引換額（34）・コレクト内消費税額等（35）が**必須**。コレクトは30万円以下、宅急便コンパクトコレクトは3万円以下。 |
| 着払い | ご請求先顧客コード（40）・ご請求先分類コード（41）・運賃管理番号（42）は**非入力項目**。 |
| クロネコゆうメール | ご請求先顧客コード（40）・分類コード（41）・運賃管理番号（42）は**非入力項目**。敬称（18）はクロネコゆうメールのみ指定可能。 |
| タイム | 配達時間帯（7）はタイム用コード（0010: 午前10時まで / 0017: 午後5時まで）。 |
| 発払い（複数口） | 個数口枠の印字（39）は「3: 枠と口数を印字する」**固定**。複数口くくりキー（74）が**必須**。クロネコwebコレクト申込受付番号（45-47）は設定不可。 |
| 宅急便コンパクト / 同コレクト | 個数口枠の印字（39）は**対象外**。 |
| ネコポス | 投函予定メール（87-89）・投函完了メール（90-95）が指定可能。 |
| クロネコゆうパケット | 投函予定/完了メールを指定してもメールは送信されない。 |
| EAZY（置き配） | 送り状種類=「1」、お届け予定eメール利用区分（48）=「1」、お届け予定eメールe-mailアドレス（49）=受取人、入力機種（50）=「1」、お届け予定eメールメッセージ（51）=空欄。詳細は [EAZY資料](EAZY送り状発行データレイアウト入出力用.md)。 |

| 利用機能 | 必須となる項目 |
|----------|----------------|
| 営業所止置き（36=1） | 営業所コード（37） |

| お届け予定/完了eメール（48/52=1） | 対応する e-mailアドレス（49/53） |
| 直送り | 連携管理番号（96）、通知メールアドレス（97、メール通知時） |
